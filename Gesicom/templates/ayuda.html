Encuentra respuestas para trabajar con tus evidencias y tu cuenta.

¿Cómo empiezo a usar GESICOM? {% icon 'chevron' %}

Crea una cuenta e inicia sesión con tu usuario o correo. Comenzarás con el rol de usuario. El administrador puede asignarte el rol que corresponda a tu trabajo.

¿Cómo envío una evidencia? {% icon 'chevron' %}

Entra a “Enviar evidencia”, indica el nombre y el proyecto, selecciona el tipo y añade un archivo o un enlace. Revisa los datos antes de enviarlos. El registro quedará disponible en “Evidencias”.

¿Qué archivos puedo adjuntar? {% icon 'chevron' %}

PDF, Word, Excel, PowerPoint, texto, JPG, PNG, ZIP y RAR, con un máximo de 10 MB. También puedes añadir un enlace HTTP o HTTPS. Comprueba que el equipo revisor pueda acceder al contenido.

¿Qué significa el estado de mi evidencia? {% icon 'chevron' %}

“En revisión” indica que el registro está pendiente. “Aprobada” confirma la revisión. Si aparece “Rechazada”, consulta las observaciones y corrige el contenido desde el detalle de tu evidencia.

¿Cómo recupero mi contraseña? {% icon 'chevron' %}

Selecciona “¿Olvidaste tu contraseña?” al iniciar sesión. Ingresa tu correo y verifica el PIN de seis dígitos recibido antes de elegir una nueva contraseña. Caduca en {{ pin_minutos }} minutos y solo puede usarse una vez. Revisa también la carpeta de correo no deseado.

¿Puedo corregir una evidencia? {% icon 'chevron' %}

Abre el detalle de una evidencia propia que esté en revisión o rechazada y elige “Corregir evidencia”. Actualiza el archivo o enlace y explica qué cambió. Volverá a revisión, conservando la fecha de primera entrega y el plazo original. Las evidencias aprobadas no admiten correcciones del propietario. Puedes consultar cada movimiento en el historial.

¿Cómo descargo los reportes? {% icon 'chevron' %}

Abre “Reportes”, elige el proyecto y el período, y aplica los filtros. Puedes descargar los registros en CSV o consultar el resumen trimestral. La información disponible depende de tu rol.

¿Dónde consulto mis entregas pendientes? {% icon 'chevron' %}

En “Mis plazos” puedes filtrar las entregas próximas, vencidas o registradas. Usa “Enviar reporte” para asociar una evidencia al plazo. Si entregaste tarde, el registro conservará ese estado aunque después se amplíe la fecha. La administración puede consultar el seguimiento por destinatario y exportar los resultados.

¿Cómo organizo mis notificaciones? {% icon 'chevron' %}

Abre la campana y entra a tu bandeja. Busca por título o mensaje y filtra por tipo o lectura. Puedes marcar avisos individuales, una selección o todos los resultados como leídos. Las preferencias de correo no eliminan los avisos de tu bandeja.

¿Puedo ver mis plazos en un calendario? {% icon 'chevron' %}

En “Mis plazos”, selecciona “Calendario” y el mes que quieras consultar. Puedes filtrar por proyecto, estado o texto, y abrir una entrega para ver sus indicaciones, enviar el reporte o consultar tus evidencias. En el celular se muestran los días que tienen entregas.

¿Cómo llevo los plazos a Google Calendar u Outlook? {% icon 'chevron' %}

Usa “Descargar plazos (.ics)” e importa el archivo desde tu aplicación de calendario. Incluye todos los resultados de los filtros, también los de otras páginas. Comprueba la zona horaria de tu calendario. La descarga es una copia: los cambios posteriores y los plazos archivados no se sincronizan automáticamente. La importación no envía invitaciones a otras personas.

¿Dónde consulto la actividad administrativa? {% icon 'chevron' %}

Si tienes el rol de administrador, entra al centro de operaciones y selecciona “Ver historial” en “Actividad reciente”. Busca una cuenta, acción o ruta, filtra por fechas y despliega los detalles. “Descargar CSV filtrado” incluye todos los resultados, también los de otras páginas. Una respuesta HTTP indica cómo respondió la solicitud; una redirección puede incluir mensajes de validación.

¿Necesito cambiar mi rol o mis datos? {% icon 'chevron' %}

Puedes actualizar tus datos en “Mi perfil”. Para cambiar de rol, solicita apoyo al administrador del centro. Nunca compartas tu contraseña.

¿Necesitas más orientación?

El administrador de tu centro puede ayudarte con los accesos y la gestión de tu cuenta.
